# DJI Media Organizer

一个 agent skill：把 DJI Osmo / Action 等设备导出的原始素材，按**实际拍摄日期**整理为 `YYYYMMDD`
命名的子目录。每次执行前都会询问是否清理 `.LRF` 预览文件。

**不限定目录**：指定哪个目录就扫哪个（递归），`YYYYMMDD/` 就建在该目录下；
不指定就扫当前项目目录。不绑定任何 agent——只有一个 `SKILL.md`，放进你的 agent 扫描
skills 的目录即可用。

## 适用场景

- SD 卡挂载后目录长这样：`/Volumes/<设备名>/DJI Device/<相机名>/DJI_001/`，
  里面有几百个 `DJI_20260920..._D.MP4`
- 想把它们按拍摄日期归档成 `20260920/`、`20260921/`，**与 `DJI_001/` 平级**
- 素材也可能直接散在某个目录下，或分散在 `DJI_001/`、`DJI_002/` 多个编号目录里——都会被
  递归扫到并汇总
- 不再需要 `.LRF`（Mimo App 用的 720p 预览，对归档没用）

## 安装

把**包含 `SKILL.md` 的整个文件夹**放进你的 agent 扫描 skills 的目录。
那个目录叫什么由你的 agent 决定（常见是 `~/.<agent>/skills/` 或 `<项目根>/.<agent>/skills/`），
不确定就查它的文档。

```bash
git clone https://github.com/song52wow/dji-media-organizer.git
mkdir -p ~/.agents/skills          # ← 换成你的 agent 实际的 skills 目录
cp -r dji-media-organizer ~/.agents/skills/
```

## 使用

指定目录：

- "整理 /Volumes/dji 共享给我/DJI Device/OsmoNano-CBF0/"
- "把 DJI_001 按日期分类"（扫描目标 = `DJI_001/`，日期目录建在 `DJI_001/` 下；若不希望如此，
  改指它的父目录，编号目录会被自动递归扫到）

不指定目录时扫当前项目：

- "整理素材"
- "按日期分类"
- "按年月日归档"

skill 会：

1. 确定扫描目标（用户指定 → 该目录；否则 → 当前项目目录）与归档根
2. **递归**扫描素材，跳过已有的 `YYYYMMDD/`（防止二次归档）
3. 分类：文件名带日期 / 继承主体的 sidecar / 读不出日期，并统计日期分布
4. 统计 `.LRF` 数量与大小，**问你怎么处理**（删除 / 归档 / 取消）
5. 读实际拍摄时间，**探测时区偏移**后与文件名交叉校验（一致率必须 100%）；
   文件名里没有日期的，用元数据定日期并标注为「由元数据推断」
6. **先给出归档计划表**让你确认，再动文件
7. 检查同名冲突与磁盘空间，建 `YYYYMMDD/` 并逐个移动（不覆盖已有文件）
8. 清理 macOS 的 `._` 影子文件
9. 校验文件数与字节数，输出报告

## 文件命名

正常情况下 DJI 文件名自带日期：`DJI_20260920150156_0001_D.MP4`。

文件名**不含日期**时（相机改名、第三方导出、伪日期如 `DJI_20261332_...`）：

| 情况 | 处理 |
|---|---|
| `X.MP4` 与 `X.SRT` / `X.THM` | sidecar 继承主体的日期 |
| 非 DJI 格式但含 `YYYYMMDD`（如 `VID_20260920.mp4`） | 按该日期归档，并用元数据校验 |
| 完全读不出日期 | 用元数据 `creation_time` / EXIF 定日期，报告里标注「由元数据推断」 |
| 元数据也没有时间 | **问你**：跳过 / 移到 `未标注日期/` / 用文件系统时间当日期 |

## 工作流示例

```
原始：
  DJI_001/
    DJI_20260920150156_0001_D.MP4
    DJI_20260920170715_0002_D.MP4
    ...
    DJI_20260920150156_0001_D.LRF
    ...
  DJI_002/
    DJI_20260921093000_0005_D.MP4
    ...

整理后（与编号子目录平级）：
  20260920/
    DJI_20260920150156_0001_D.MP4
    ...
  20260921/
    DJI_20260921093000_0005_D.MP4
    ...
  DJI_001/        ← 清空，只剩 .DS_Store
  DJI_002/        ← 清空
```

## 不会触发的场景

- ❌ 视频转码 / 剪辑
- ❌ 素材去重
- ❌ 非 DJI 相机且文件名不带 `YYYYMMDD_HHMMSS` 的素材
- ❌ 上传到云盘

## 依赖

需要能跑 shell 命令（`mv` / `du` / `find`）和能向用户提问。`ffprobe` 用于读视频拍摄时间，
`sips` / `mdls` / `dot_clean` 仅 macOS。完整依赖与降级路径见 `SKILL.md` 末尾的「依赖」表。
